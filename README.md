# 🐾 Animal World Website

## 📌 Overview

Animal World is a simple, responsive website built using **HTML, CSS, and JavaScript**. It introduces users to different animals, their habitats, and provides fun interactive facts.

This project is ideal for beginners learning front-end development or for educational purposes.

---

## 🚀 Features

* 🦁 **Featured Animals Section**

  * Displays animals like Lion, Elephant, Dolphin, and Eagle
  * Includes images and descriptions

* 🌍 **Habitats Section**

  * Explains where animals live (forest, ocean, desert, grassland)

* 🎯 **Fun Fact Generator**

  * Interactive button that displays random animal facts

* 📱 **Responsive Design**

  * Works on desktop, tablet, and mobile devices

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

- Add more facts in the JavaScript array
